🎓 SkillSwap Campus

A Student-to-Student Skill Sharing Platform

SkillSwap Campus is a web-based platform designed to help college students learn, share, and exchange skills with each other. It connects students who want to learn new skills with students who can teach those skills.

Our goal is to build a collaborative campus community where students can grow together by sharing their knowledge and expertise.

🌟 Features

- 👤 Student Profiles: Students can create profiles and showcase their skills.
- 🔐 User Authentication: Students can sign in to access the platform.
- 🤝 Skill Sharing: Connect with other students to learn and share skills.
- 🌐 Student Discovery: Explore student profiles and discover new learning opportunities.
- 💻 User-Friendly Interface: Simple and accessible web design.
- ☁️ Cloud Database: Firebase integration for storing and managing student data.
- 📱 Web-Based Platform: Access the platform through a web browser.

🎯 Problem Statement

Many college students have valuable skills but lack an easy way to share their knowledge with other students. At the same time, students often struggle to find peers who can help them learn new skills.

SkillSwap Campus aims to solve this problem by creating a common platform for peer-to-peer learning and skill exchange.

💡 Our Solution

SkillSwap Campus provides a digital space where students can showcase their skills, discover other learners, and connect with peers for collaborative learning.

Instead of learning alone, students can learn from each other and build a stronger campus community.

⚙️ Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

[git clone YOUR_GITHUB_REPOSITORY_URL](https://github.com/nitin01435-blip/skillswapcampus.git)

2. Open the Project Folder

cd SkillSwap-Campus

3. Open in VS Code

Open the project folder in Visual Studio Code.

4. Configure Firebase

- Open the Firebase Console.
- Create or select your Firebase project.
- Configure Firebase Authentication and the required database.
- Add your Firebase configuration to the appropriate JavaScript file.
- Ensure your Firebase security rules are configured correctly.

5. Run the Website

Open "index.html" using the VS Code Live Server extension, or use your configured local development server.
